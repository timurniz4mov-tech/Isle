# ISLE Survival 1.20.1 — исправление отображения оружия

## Что исправлено
- Для пяти 3D-моделей оружия добавлен `layer0`, чтобы Minecraft мог гарантированно создавать значок предмета в инвентаре и хотбаре.
- Удалена дублирующая плоская геометрия профиля: плоский силуэт теперь создаётся стандартным item/generated-слоем, а дополнительные кубоиды добавляют объём.
- Версия проекта обновлена до `0.1.1`.

## Как обновить мод
1. Замените содержимое своего репозитория файлами из этого архива (или загрузите только пять JSON-файлов из `src/main/resources/assets/islesurvival/models/item/`).
2. В GitHub откройте **Actions** и дождитесь успешной сборки.
3. Скачайте артефакт `isle-survival-forge-1.20.1`.
4. Удалите старый `islesurvival` JAR из `.minecraft/mods` и положите туда новый JAR. Не оставляйте две версии одного мода одновременно.
5. Запустите Minecraft с Forge 1.20.1. В мире с включёнными читами выполните `/isle arsenal`. Команда выдаёт всё оружие и подходящие патроны.

## Если хотбар всё ещё пустой
- Проверьте, что команда `/isle arsenal` распознана игрой и вывела сообщение «Тестовый арсенал выдан».
- Откройте творческий инвентарь и найдите вкладку «ISLE: Выживание».
- Проверьте, что в папке `mods` остался только один JAR `islesurvival`.
- После замены JAR нажмите `F3 + T`, чтобы перезагрузить ресурсы.

Примечание: исходники и JSON-модели проверены на синтаксис. Полноценная сборка Forge и проверка отображения внутри клиента в этой среде не выполнялись.
