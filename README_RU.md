# ISLE Survival — Minecraft Forge 1.20.1

Первая самостоятельная версия приключенческого мода в духе Roblox Isle (Badorkbee). Проект не использует игровые файлы, модели, текстуры или исходный код Roblox Isle: все добавленные ресурсы созданы для этого проекта.

## Что уже заложено в этой версии

### Карта острова

Карта строится прямо в игре командой `/isle start`. Запускай её **один раз в новом мире**: команда создаёт остров вокруг игрока и перемещает его на стартовую точку.

На острове предусмотрены:
- пляжи, холмы, лес и окружающий океан;
- кораблекрушение с первым тайником;
- исследовательская станция с подземной технической комнатой;
- радиовышка;
- маяк;
- эвакуационный причал и площадка;
- тайники с оружием, патронами, аптечками, ключ-картой и деталями радиомаяка.

Команда меняет область мира примерно 250×250 блоков вокруг игрока, поэтому её лучше выполнять в свежем мире, а не на своей основной карте.

### Оружие

Все пять видов оружия используют правую кнопку мыши и расходуют подходящие патроны из инвентаря.

| Оружие | Особенности |
|---|---|
| Охотничья винтовка | Точный одиночный выстрел, средняя скорострельность |
| Охотничья винтовка с оптикой | Большой урон и дальность, медленная перезарядка между выстрелами |
| Самозарядная винтовка | Быстрые одиночные выстрелы |
| Пистолет-пулемёт | Небольшой урон, короткий интервал между выстрелами |
| Помповый дробовик | Несколько дробин за выстрел, эффективнее вблизи |

Патроны: `Винтовочные патроны` и `Патроны для дробовика`.

### Другие механики

- «Охотник» — сильный враждебный монстр, который появляется ночью после начала третьего игрового дня.
- Наёмники — группы враждебных мобов с арбалетами, появляющиеся с третьего дня.
- Аптечки восстанавливают здоровье.
- Сухой паёк утоляет голод.
- Ключ-карта и детали радиомаяка спрятаны в тайниках.
- Первый маршрут побега: найди 1 ключ-карту и 2 детали радиомаяка, затем введи `/isle escape`; продержись 30 секунд до завершения эвакуации.

## Команды

- `/isle start` — построить остров и перенести игрока на старт.
- `/isle arsenal` — выдать все виды оружия, боеприпасы и аптечки для тестирования.
- `/isle escape` — начать радиопобег при наличии нужных предметов.
- `/isle help` — показать подсказку.

## Сборка через GitHub Actions

1. Создай пустой репозиторий или открой репозиторий для этого проекта.
2. Загрузи **содержимое** этой папки в корень репозитория (папка `.github` тоже должна попасть в корень).
3. Открой вкладку **Actions**. Workflow `Build ISLE Survival` запустится после push; его также можно запустить вручную через `Run workflow`.
4. Открой успешный запуск и скачай артефакт `isle-survival-forge-1.20.1`.
5. Помести полученный `islesurvival-0.1.0.jar` в папку `mods` игры с Forge 1.20.1.

Для разработки нужен JDK 17. Сборка настроена на Minecraft 1.20.1, Forge 47.2.0 и Gradle 8.1.1.

## Важно: статус версии

Это **играбельная основа/первый прототип**, а не законченный полный ремейк Isle. Карта генерируется командой, оружие уже стреляет и использует боеприпасы, а монстр и патрули имеют базовое поведение. Пока не реализованы полноценные многоэтапные концовки/побеги, система заданий, сложная тактика наёмников, анимации прицеливания и перезарядки, 3D-модели оружия и полноценный интерфейс дней. Эти вещи можно добавлять следующими обновлениями после проверки первой сборки.

## Структура

- `src/main/java` — код мода, оружия, сущностей, карты и команд;
- `src/main/resources` — модели предметов, текстуры и переводы;
- `map` — план карты и заметки по её развитию;
- `.github/workflows/build.yml` — автоматическая сборка JAR.
